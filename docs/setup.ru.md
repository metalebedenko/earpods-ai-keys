# Установка и удаление

## Подготовка

Нужны проводные USB-C Apple EarPods с VID `0x05ac`, PID `0x110b`, HID-страницей Consumer Control `12` и usage `1`. Физически проверен Mac mini M4 с macOS 27.0.1. Другие конфигурации требуют подтверждения.

1. Подключите EarPods.
2. Откройте **Системные настройки → Клавиатура → Диктовка**. Включите диктовку, выберите язык и микрофон EarPods.
3. Сохраните своё сочетание запуска диктовки с клавиатуры. Центр посылает VoiceCommand, а не имитирует это сочетание. **Для проверенного профиля выключите Siri вручную в Системных настройках → Siri** и запомните её исходное состояние для отката.
4. Скачайте папку проекта или клонируйте репозиторий. Откройте терминал в этой папке. После публикации клонирование выглядит так:

```sh
git clone https://github.com/metalebedenko/earpods-ai-keys.git
cd earpods-ai-keys
```

Пароль администратора и отдельное приложение для переназначения не нужны. Скрипт сам не меняет диктовку, Siri, разрешения микрофона и предпочтения обработки речи. Если Siri должна оставаться включённой, этот проверенный профиль центра не подходит; альтернативный запуск пока не подтверждён.

## Команды

```sh
/bin/sh ./earpods-ai-keys.sh status
/bin/sh ./earpods-ai-keys.sh install
/bin/sh ./earpods-ai-keys.sh status
```

`status` показывает состояние переназначений подключённого устройства и установки проекта. Отсутствие устройства, чужое правило и ошибка — отдельные состояния. Наличие файла автозапуска ещё не подтверждает работу кнопок.

`install` помещает рабочие файлы в `~/Library/Application Support/EarPods AI Keys/` и добавляет `~/Library/LaunchAgents/local.earpods-ai-keys.plist`. Задание имеет только `RunAtLoad`: без повторяющегося интервала и `KeepAlive`. При подключённых EarPods и пустом либо уже принадлежащем проекту правиле три пары могут примениться сразу.

Чужие непустые переназначения сохраняются; установка отказывается заменять конфликтующие файлы. Ранее настроенный персональный агент `local.earpods-macos-dictation` считается отдельной установкой. Публичный пакет не переносит и не заменяет его автоматически. Установить пакет без подключённых EarPods можно, но перед использованием кнопок потребуется подключить их и выполнить `apply`.

Если исходную скачанную папку уже удалили, установленный скрипт доступен по команде:

```sh
/bin/sh "$HOME/Library/Application Support/EarPods AI Keys/earpods-ai-keys.sh" status
```

Вместо `status` можно указать `apply` либо `uninstall`. Команда `install` использует исходный комплект с шаблоном.

### Коды завершения

| Код | Значение |
|---|---|
| 0 | Команда завершена; `status` при этом может сообщать об отсутствии устройства или чужом правиле |
| 1 | Ошибка инструмента или файловой системы |
| 2 | Неверные аргументы |
| 3 | EarPods отсутствуют при ручном `apply` |
| 4 | Конфликт правила, файлов либо прежней установки |

## Проверка физических кнопок

Сначала откройте пустой текстовый документ и поставьте курсор в поле редактирования.

1. Нажмите и отпустите центральную кнопку, затем продиктуйте короткую фразу.
2. Нажмите «−»: должен удалиться символ перед курсором либо выделенный текст. Это обычный Backspace.
3. Нажмите «+»: документ должен получить Enter.
4. Повторите в нужном поле приложения ИИ. Enter выполняет действие, принятое в этом приложении. В терминале он может выполнить команду.

На Apple silicon Mac автора можно было удалять символы во время диктовки и продолжать говорить. Apple также описывает ввод с клавиатуры во время диктовки на Apple silicon. Это не подтверждает такое же поведение на любой конфигурации.

## После входа и переподключения

Правило `hidutil` временное. Apple документирует сброс после перезагрузки системы либо удаления соответствующей HID-службы. Для однократного применения при входе EarPods должны быть уже подключены.

Если подключили их позже или правило пропало:

```sh
/bin/sh ./earpods-ai-keys.sh apply
/bin/sh ./earpods-ai-keys.sh status
```

Пакет не ожидает подключений в фоне. Реальный следующий вход и переподключение нужно проверить на своей машине: первоначальная физическая проверка автора эти сценарии не включала.

## Удаление

```sh
/bin/sh ./earpods-ai-keys.sh uninstall
```

Команда останавливает свой автозапуск и удаляет принадлежащие установке файлы. Владение проверяется по маркеру и контрольным суммам. Если файлы установки изменены, заменены или потеряны, удаление останавливается для разбора. Дополнительные файлы сохраняются.

Правило подключённых наушников очищается только при точном совпадении с тремя парами проекта. Чужие и нераспознанные правила сохраняются. При обнаружении прежней персональной установки правило также не очищается: она может его использовать. Если EarPods отключены, проверить и очистить их текущее правило нельзя; после подключения проверьте реальные кнопки, прежде чем считать пульт штатным.

Настройки диктовки и Siri, изменённые вручную, остаются системными предпочтениями. Если хотите вернуть точные параметры до теста, восстановите их исходные значения после удаления пакета. Можно также намеренно оставить Siri выключенной — именно такой итоговый выбор сделал автор на втором Mac. Пока правило проекта активно, три кнопки заменяют свои обычные музыкальные функции.
