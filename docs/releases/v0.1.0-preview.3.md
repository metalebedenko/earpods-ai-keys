# EarPods AI Keys 0.1.0 — preview 3

A native macOS menu-bar app that turns Apple USB-C EarPods into Dictation, Backspace and Enter buttons.

## Download

**Apple silicon (ARM64)** · app version **0.1.0**, build **3** · **MIT**.

Download `EarPods-AI-Keys-0.1.0-preview.3-arm64.dmg` from the assets below. Open it, drag the app into Applications, eject the image and launch the installed copy.

**This is an ad-hoc signed preview, not notarized by Apple.** For an unverified-developer warning on a trusted download, use System Settings → Privacy & Security → Open Anyway after attempting to open it. [Apple instructions](https://support.apple.com/en-us/102445). No global Gatekeeper changes are required.

Enable macOS Dictation and **turn Siri off manually** for the tested center-button behavior. Connect USB-C EarPods, then choose «Включить пульт» from the menu. The current interface is in Russian.

## Included

- Center: native macOS Dictation; minus: Backspace; plus: Enter.
- Per-button key or key-combination assignment, optional login startup, device-event reconnection and an in-app uninstall action.
- Source and no third-party runtime dependencies. Speech recognition is supplied by macOS, without an offline guarantee.

Standard input and reconnection were physically tested on two Macs with macOS 27.0.1; the second also passed both reboot/connection scenarios. Undo with ⌘Z and full uninstall/reinstallation were tested on the first Mac. Other OS versions, Intel downloads and other headsets are unverified. Enter follows the focused app, including command execution in a terminal.

The public asset removes build-machine debug symbol paths and is re-signed ad hoc. All 36 main-app and 33 helper runtime sections are byte-identical to the tested build 3. The repackaged asset has not had a separate hardware run. Its signature differs from earlier private copies, so custom-key permissions may require renewed approval.
