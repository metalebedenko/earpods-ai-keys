EarPods AI Keys — обновление 2026-10-09

Исправлен пустой ответ hidutil при отключённых наушниках.

Подключите EarPods. Запускайте команды из этой распакованной папки:
/bin/sh ./earpods-ai-keys.sh uninstall
/bin/sh ./earpods-ai-keys.sh install
/bin/sh ./earpods-ai-keys.sh status

Не заменяйте вручную файлы в Library/Application Support: они защищены контрольными суммами.
Новая версия удалит принадлежащую пакету установку и создаст её заново.
Настройки диктовки и Siri не переключаются. Для проверенной диктовки Siri должна быть выключена.
При отключённых наушниках install разрешён, но после позднего подключения нужен apply вручную.
