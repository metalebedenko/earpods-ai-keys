## Пост 1

Купил проводные USB-C EarPods. Оказалось, их музыкальный пульт удобно использовать для ввода на Mac.

Центр — диктовка, «−» — Backspace, «+» — Enter. Надиктовал промпт, поправил, нажал Enter. Так появился EarPods AI Keys.

## Пост 2

Сейчас это небольшое приложение в строке меню Mac. Можно включить пульт, переназначить три кнопки и записать сочетание вроде ⌘Z.

Оно замечает подключение наушников и восстанавливает назначения. Есть автозапуск по желанию и удаление из меню. Дополнительный ремаппер устанавливать не нужно.

## Пост 3

Главный нюанс: для проверенной схемы нужно вручную выключить Siri и включить диктовку macOS.

Распознаёт речь сама macOS, текст появляется в активном поле. Интеграции с ChatGPT или Codex здесь нет. Обработка голоса зависит от системной диктовки, поэтому полный офлайн не обещаю.

## Пост 4

Базовые кнопки проверил на двух Mac с macOS 27.0.1. На втором прошли переподключение, перезагрузка с наушниками и запуск без них с поздним подключением.

На первом ещё проверил ⌘Z, выключение режима и удаление. Другие системы пока ждут проверки. А «+» нажимает обычный Enter: его действие зависит от активного окна.

## Пост 5

Пока это ранний preview для Apple Silicon (ARM64). Сборка подписана ad-hoc, без нотарификации Apple. macOS может заблокировать первый запуск; в README есть путь разрешения для конкретного приложения.

Для сочетаний клавиш нужны дополнительные разрешения macOS. Существующие чужие назначения пульта приложение сохраняет.
